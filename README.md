# 🎂 How Old? — Age Milestone Explorer

A playful web app to explore fun, round-number age milestones — like your 10,000th day, 1 millionth minute, or 1 billionth second alive. Just enter your date of birth and we’ll do the rest!

---

## 📅 Features

| Feature                         | Status     | Description                                                                 |
|-------------------------------|------------|-----------------------------------------------------------------------------|
| DOB Input Form                | ✅ DONE     | Input for date of birth, with optional time of birth.                      |
| Next Metric Birthday Engine   | ✅ DONE     | Calculates next round number milestone in all major time units.           |
| Detailed Breakdown Section    | ✅ DONE     | Explore upcoming and past milestones for each unit.                       |
| Past Milestone Checker        | ✅ DONE     | Lists recent major milestones you’ve already passed.                      |
| Clean UI/UX Design            | ✅ DONE     | Crisp, responsive layout with playful animations and emoji accents.       |
| Shareable Milestone URLs      | ✅ DONE     | Copy a unique link to revisit any countdown.                              |
| Add to Calendar Support       | ✅ DONE     | Add any milestone to your 📅 calendar (ICS + Google Calendar).            |

---

## ⏱ Metric Time Units

The app tracks your age in various time units and milestones:

- **Years** (e.g. 30, 33, 40)
- **Months** (e.g. 500, 1000)
- **Weeks** (i forgot to add)
- **Days** (e.g. 10,000, 15,000)
- **Hours** (e.g. 100,000, 200,000)
- **Minutes** (e.g. 10 million, 50 million)
- **Seconds** (e.g. 1 billion, 2 billion)

---

## 🛠 Tech Stack

- **HTML/CSS/JS** — Vanilla frontend, fully portable and framework-free
- **LocalStorage + URL Params** — For persistence and shareable links
- **ICS + Google Calendar APIs** — One-click calendar support
- **GitHub Pages** — Easy deployment (no server needed)

## 🚀 Usage

Visit: [https://naddot.github.io/how-old/](https://naddot.github.io/how-old/)

1. Enter your date (and optional time) of birth
2. See your current age in multiple units
3. View upcoming & past round-number milestones
4. Click into units for a deep dive
5. Add milestones to your calendar or share a live countdown
